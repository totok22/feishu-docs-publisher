# 0.4.0

## Added

- Choose which files and folders to sync with the new Sync ignore page. Rules are saved in `.feishuignore` files with gitignore-style patterns and apply to folder sync, sync on save, and Git pre-push.
- Folder sync collects images that no note embeds into a gallery note in the same folder. Later syncs refresh the gallery as images change.
- An optional setting lists published documents and PDFs whose local files no longer exist, then asks for confirmation before deleting them from Feishu/Lark. It is off by default.
- Folder sync shows its current step in the Published files window and progress notifications. Closing the window lets the sync continue.

## Fixed

- Missing local folder bindings no longer lead directly to creating another remote folder. The plugin restores a unique same-name Drive folder under the same parent when it is not bound elsewhere. Ambiguous folders and same-name Wiki pages require an explicit folder link.
- Folder recovery is saved immediately. Concurrent requests and retries after changing the default target retain protection against duplicate creation.
- Image uploads resume using saved block IDs, including interruptions before an image is moved into position. The plugin and Git pre-push share these records and no longer mistake an adjacent same-name image for the uploaded image.
- Notes ending with a local image no longer fail when the image is already in its intended position.
- Ignored folders keep their remote directory pages untouched, including during overwrite sync. Re-including a folder restores its descendants when deeper rules allow it.
- Gallery notes clear old image references when the last image is removed or all images are ignored, while preserving their remote bindings.
- Folder sync from the Published files window also runs the configured remote cleanup after a successful sync.
- PDF progress now says “Checking and syncing” because unchanged PDFs can be checked and skipped without uploading again.

Requires Obsidian 1.13.0 or later on desktop.
