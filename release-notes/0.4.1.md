# 0.4.1

## Added

- Embed vault-local MP4, M4V, MOV, and WebM videos with `![[clip.mp4]]` or `![Demo](assets/clip.mp4)`. Videos appear as Feishu/Lark file previews. Playback depends on the codec and client.
- Reuse unchanged videos when syncing again or editing nearby text. Sync on save and Git pre-push also detect changes to referenced video files. Interrupted uploads resume from saved block IDs.

## Changed

- Folder scans traverse only the selected subtree. Attachment changes read only bound notes through Obsidian, and note sync builds its image and video index from the vault file list. Gallery notes continue to collect images only.

## Fixed

- Video examples in indented code, inline code, fenced code, and HTML comments no longer require real video files or prevent syncing. Longer code fences correctly contain shorter fence examples.
- Video upload errors identify videos instead of images. Upload recovery records receive additional type checks.
- Delete confirmation buttons use Obsidian's destructive action style.

Thanks to @KevinYoung-Kw for contributing local video support in [PR #2](https://github.com/totok22/feishu-docs-publisher/pull/2).

Requires Obsidian 1.13.0 or later on desktop.
