# 0.4.2

## Added

- Export Obsidian callouts as native Feishu/Lark parent and child blocks with the new **Native Callout folding** setting. Nested callouts, lists, code, and local images and videos stay inside their parent, and `-` / `+` set the initial fold state. It is off by default. See [Native Callout and PDF export](https://github.com/totok22/feishu-docs-publisher/blob/main/docs/native-export.md) for migration notes and limits.
- Render PDF pages and regions as images with `![[paper.pdf#page=3]]` and `![[paper.pdf#page=3&rect=10,20,110,70|300]]`. Images keep their size and a page caption. Plain PDF links such as `[[paper.pdf#page=3|Reference]]` now keep their alias and page text.
- Highlight bold labels before a colon, such as `**Conclusion**: ...`, in red text on a yellow background with the new **Research label colors** setting. It applies to native export only and is off by default.
- Rebuild an existing release tag on demand from the release workflow.

## Changed

- **Write frontmatter binding** is now off by default. Bindings stay in plugin data, and you can turn the setting on to write them to notes. Saved values are kept when you upgrade.

## Fixed

- Media scanning now ignores references inside nested code, inline code, and HTML comments, while still finding real references later on the same line as a comment.
- PDF crop cache files are written atomically. A damaged cache is rendered again, and images with invalid dimensions are rejected.
- With frontmatter writing off, unbinding a document deleted remotely only updates plugin data and leaves the note unchanged. A removed binding no longer comes back from old properties.

Converting an existing document to native Callouts rebuilds its body: the URL stays, but block IDs and comments may be lost. Merge remote edits into the note first. Native export needs the `docx:document.block:convert` permission in `lark-cli`.

Thanks to @HeShiLie for the native Callout and PDF export work in their [fork](https://github.com/HeShiLie/feishu-docs-publisher).

Requires Obsidian 1.13.0 or later on desktop.
